# Security policy

Please report suspected security problems privately, through GitHub's "Report a vulnerability" button on the repository's Security tab. Do not open a public issue or pull request for them.

Include the version, a description of what you saw and, if you can, the smallest steps that reproduce it. Use made-up data only; never send real credentials or customer data. We will acknowledge your report and keep you informed about the fix.

Only the latest released version receives fixes.

This is a community project and is not affiliated with Selcom Paytech Ltd. For problems with the Selcom API itself, contact Selcom.
